## Независимая временная проверка

Обучение: 6–16 апреля; проверка: 17–19 апреля, 1 951 кука, 160 положительных.

| Модель | P@R≥0.70 | Average Precision | ROC-AUC |
|---|---:|---:|---:|
| baseline_rf | 0.0931 | 0.1627 | 0.5749 |
| hgb_31 | 0.7417 | 0.7732 | 0.9322 |

По дням P@R≥0.70 выбранной модели: 17 апреля - 0.8545; 18 апреля - 0.5968;
19 апреля - 0.6977. Это метрики с отдельными оптимальными порогами, их среднее
не равно общей метрике. Описательный 95%-й percentile-интервал bootstrap по кукам:
[0.5641, 0.8547]. Он не учитывает зависимость внутри источников/дней и не является
гарантией результата на скрытом тесте. AP - Average Precision, не трапецеидальная PR-AUC.

После проверки конфигурация не менялась. Для submission выбранная модель
переобучена на всех 11 091 куках train; получено ровно 4 909 предсказаний.
На платформу ничего не отправлялось: 7 попыток не расходованы.

## Данные и признаки

Из 328 905 строк событий исключены 40 779 строк вне индивидуального окна.
После фильтра окна удалены 2 952 полных дубля в train и 1 341 в test.
Итог: 195 484 события train, 88 349 test. Все куки имеют события после обработки.
Окно строго полуоткрытое: начало включено, конец исключён.

Основные группы признаков:

- Число событий и уникальных объявлений, доли десяти типов событий.
- Длительность активности, интервалы между событиями, их квантили и вариативность,
  доли коротких пауз, повторяемость интервалов, активные минуты/часы и сессии.
- Разнообразие и концентрация категорий, локаций, объявлений, запросов и действий.
- Глубина поиска и последовательное листание страниц.
- Контактные действия, фотографии и избранное относительно числа просмотров.
- Наличие координат курсора, разнообразие точек и величина наблюдаемых перемещений.
- Нормализованная платформа, общие признаки User-Agent без версий и полной строки.
- Возраст куки на конец окна, возраст на начало и создание внутри окна.

Сырые cookie_id, item_id, тексты запросов, значения категорий/локаций и абсолютные даты
не подаются модели. Нет межкуковых агрегатов, target encoding или глобальных
частот, рассчитанных на train+test. EID дублирует event_name и не используется.

NaN в статистике означает отсутствие наблюдений; HGB обрабатывает их напрямую.
В ExtraTrees медианный imputer с индикаторами пропусков обучается внутри каждого
обучающего фолда. Куки без событий поддерживаются и не исчезают после join.

## Запуск

Проверенная версия: **Python 3.12.14**, Linux, CPU, один поток. Версии библиотек
зафиксированы в `requirements.txt`. Для просмотра notebook используйте Jupyter
или VS Code с поддержкой notebook; они не нужны для командного запуска.

Положите три исходных файла в `data/` рядом с кодом. Исходные данные в архив
решения не включены: проверяющий использует выданные файлы.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python checks.py data
python solution.py --data-dir data --output-dir outputs
```

На Windows активация: `.venv\Scripts\activate`.
Альтернатива: выполнить все ячейки `solution.ipynb`. Он самодостаточен и содержит
ту же реализацию. По умолчанию читает `data/` и пишет `outputs/`.
Время выполнения зависит от CPU; основную часть занимает извлечение признаков.
После установки библиотек решение не использует сеть.

## Состав

- `solution.ipynb` - самостоятельный notebook с пояснениями и сохранёнными результатами.
- `features.py` - получение признаков; `solution.py` - валидация, обучение и запись CSV.
- `metric.py` - оригинальная метрика организаторов, без изменений.
- `checks.py` - проверки границ окна, дубликатов, куки без событий и равных score.
- `outputs/submission.csv` - файл для платформы, без округления до малого числа знаков.
- `outputs/experiments.csv` - все development-эксперименты.
- `outputs/report.json` - аудит, метрики, версии, seed и SHA256 входов/выхода.
- `outputs/holdout_predictions.csv` - проверочные предсказания по известной разметке train.
- `outputs/feature_names.txt` - признаки выбранной модели.

## Ограничения

Разметка относится к известным сервисам; идентификаторов источников нет, поэтому
leave-one-service-out невозможен. Новые боты могут отличаться. Даты покрывают короткий
период, и в ежедневных метриках виден разброс. Капча зависит от действующей защиты,
курсор - от платформы и логирования; эти признаки могут менять смысл в будущем.
Без ID события нельзя доказать, что все полные дубли являются ошибками логирования.
Score используется для ранжирования, а не как откалиброванная вероятность.
Суточная модель применима после конца окна, не для блокировки в начале дня.

## Использованные подходы и авторство

Open-source: NumPy, pandas, scikit-learn; транзитивные зависимости SciPy, joblib,
threadpoolctl. Baseline следует выданному quickstart: RandomForest по двум агрегатам,
но seed=42 и очистка событий общие для всех экспериментов. Другие кандидатские
решения не использовались. Фиксированная небольшая сетка включает два HGB и ExtraTrees.

Код подготовлен с помощью AI-ассистента. В исполняемом решении нет LLM, внешних API
и ручной разметки test. Если запрет LLM включает помощь при написании кода, а не только
модели решения, допустимость этой помощи нужно согласовать с организаторами.
